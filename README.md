# Still Awake? (Не спишь?)

Небольшая сюжетная хоррор-игра на стыке визуальной новеллы, психологического хоррора и survival.

Ночь. Героиня одна в своей комнате. На телефон приходит сообщение от незнакомца: **«Ещё не спишь?»**. Постепенно он начинает писать то, чего знать не должен. Игрок ведёт переписку, осматривает комнату, ищет полезные предметы, следит за окном и дверью и прячется, когда незнакомец подходит слишком близко. Задача — пережить ночь.

Основной цикл: **получить информацию → принять решение → исследовать или действовать → столкнуться с последствиями**. Сообщения незнакомца пишет LLM через backend, а ключевые события (где он, когда входит, кого находит) остаются за игровой логикой.

Подробно: [docs/gdd.md](docs/gdd.md) (концепция и MVP), [docs/gameplay.md](docs/gameplay.md) (правила), [docs/room.md](docs/room.md) (комната).

## Структура репозитория

```text
still-awake/
├── client/StillAwake(2D ver.)/   Unity-проект (Unity 6000.6.7f1, URP 2D). Эту папку открывают в Unity Hub
├── backend/                      Go-сервер: игроки, ночи, переписка с LLM, веб-панель с ролями; Docker
└── docs/                         геймдизайн-документы и референсы
```

Оба проекта лежат в одном репозитории: клиент и сервер меняются вместе (формат чата, состояние ночи), документация общая, а одна история коммитов проще для небольшой команды. У каждой части свой `.gitignore`, а Unity открывает папку проекта напрямую, как обычный проект.

## Быстрый старт

### Клиент (Unity)

1. Установить **Unity 6000.6.7f1** (Unity Hub предложит сам, если версии нет).
2. Unity Hub → **Add** → **Add project from disk** → выбрать папку `client/StillAwake(2D ver.)`.
3. Первое открытие идёт дольше: Unity соберёт `Library/`.
4. Нажать Play на сцене `GameMenu` или `Game` (или меню **Still Awake → Запустить игру (с меню)**): сначала откроется главное меню.

Управление, настройки клавиш, телефон и устройство кода описаны в [client/StillAwake(2D ver.)/README.md](client/StillAwake(2D%20ver.)/README.md).

### Backend (Go или Docker)

```powershell
cd backend
Copy-Item .env.example .env
go run ./cmd/server            # или: docker compose up -d --build
```

Панель — `http://127.0.0.1:8080`, вход по логину и паролю. Первый супер-админ `admin` создаётся сам: пароль из `ADMIN_INITIAL_PASSWORD` или случайный — он печатается в консоль и сохраняется в `backend/secrets/` (в git не попадает); с `DEV_MODE=true` он печатается при каждом запуске. Для нейросети запустите LM Studio на `127.0.0.1:1234` (`LLM_MODE=openai_compatible`). Подробности — [backend/README.md](backend/README.md), устройство — [backend/ARCHITECTURE.md](backend/ARCHITECTURE.md).

## Что уже сделано

**Клиент — прототип одной ночи**:

- главное меню (`GameMenu.unity`, запускается первым): «Играть», «Настройки» (клавиши и кнопки мыши; ИИ вкл/выкл, адрес сервера, проверка модели), «Выход»; без регистрации — игра подключается к серверу сама;
- нарисованная комната с дивана и четыре кадра 3000×2000 (у окна, у двери, кровать, шкаф); плавные переходы с шагами и поворотом головы;
- осмотр внутри кадра: взгляд следует за курсором, колесо приближает, M3 закрепляет камеру;
- клик по объекту — маленькое меню действий у курсора, результат — мысль героини субтитрами; подсветка по силуэту объекта;
- инвентарь-хотбар: клик — использовать, перетащить на объект — применить;
- телефон 0 / 25 / 100%: мессенджер в духе Telegram («печатает…», счётчик непрочитанных), звонилка, калькулятор, заметки; сообщения сталкера пишет нейросеть или заготовки;
- часы как во FNAF: 12 AM → 6 AM, час ≈ 90 секунд; пауза на Esc; мигание света и процедурный звук;
- свет, шторы, запирание двери, шум, два укрытия; сталкер (пока красный квадрат) ходит улица → окно → дверь → комната.

**Backend**: игроки по ключу установки (или номеру телефона), ночи и их события, переписка с моделью (системный промпт редактируется в панели, правила против подмены роли — в коде), роли и пользователи как в license-store, док-панель из pdd-trainer, аналитика, Docker.

## Работа с git

- В репозиторий идут исходники: `Assets`, `Packages`, `ProjectSettings` Unity-проекта, `backend/`, `docs/`. Всё генерируемое (`Library/`, `Temp/`, `Logs/`, `UserSettings/`, `*.csproj`, сборки, `.env`, `secrets/`, локальная БД) исключено правилами в [.gitignore](.gitignore), [client/StillAwake(2D ver.)/.gitignore](client/StillAwake(2D%20ver.)/.gitignore) и [backend/.gitignore](backend/.gitignore).
- Файлы `.meta` коммитятся всегда вместе с ассетом. Добавили картинку или скрипт — откройте проект в Unity, чтобы появился `.meta`, и только потом коммитьте.
- Интерфейс и ночь собираются кодом, в сценах — только нарисованная комната (`Game.unity`) и точки входа. Над одной и той же сценой одновременно лучше не работать.
- Исходники арта (`.kra`, `.psd`) можно хранить в `client/Assets/Art`. Если файлы начнут переваливать за 50 МБ, стоит подключить Git LFS.
