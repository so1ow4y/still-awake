KRA Importer Documentation

Purpose

The importer reads a Krita file (.kra), extracts image and layer data, rebuilds each layer into Unity-friendly pixel arrays, and allows the user to generate final merged outputs from selected sublayers.

LZF decoder is by Chaser324 Chase Pettit

Usage examples

Parse a KRA file

var parser = new KraParser();
KraImageData imageData = parser.ParseKraFile(fullKraPath);

Create a texture from a layer

Texture2D texture = KraTextureUtils.CreateTextureFromLayerPixels(imageData, layerIndex);

Merge multiple layers

Color32[] mergedPixels = KraTextureUtils.MergeLayerPixels(width, height, layersPixels);

Texture2D texture = KraTextureUtils.CreateTextureFromLayerPixels(width, height, mergedPixels);

Save texture as PNG

KraTextureUtils.SaveTextureAsAsset(texture, pngPath,
    refreshAssetDatabaseInstant: false,
    refreshAssetDatabaseWithDelay: true,
    setImporterSettings: true
);

Save texture as sprite PNG

KraTextureUtils.SaveTextureAsSprite(texture, pngPath, pixelsPerUnit: 100f,
    refreshAssetDatabaseInstant: false,
    refreshAssetDatabaseWithDelay: true
);

Import flow

  1. Unity detects a .kra file and calls KraScriptedImporter.OnImportAsset.
  2. The importer opens the file path and passes it to KraParser.ParseKraFile.
  3. KraParser opens the .kra as a ZIP archive, because .kra file is just .zip file, you can preview it if you change extension of file to .zip.
  4. maindoc.xml is parsed for image size, name, background color, layer names, opacity and UUIDs.
  5. Layer binary data is read tile by tile.
  6. KraDecoder decodes RAW or LZF-compressed tile data.
  7. KraTextureUtils pastes tile pixels into full layer pixel buffers.
  8. The importer builds merged textures from user-selected sublayers.
  9. Depending on settings, outputs are added as subassets, saved as PNG, or imported as sprite PNGs.

KraParser

KraParser is responsible for reading the .kra file and returning a populated KraImageData object.

public KraImageData ParseKraFile(string fullFilePath)

Main parser entry point. Opens a Krita file from a full system path and extracts document metadata, layer metadata, layer pixel data, and the merged preview image. 

var parser = new KraParser();
KraImageData imageData = parser.ParseKraFile(fullKraPath);

Returns

A KraImageData instance containing the image width, height, name, background color, layer array and merged image.

KraDecoder

KraDecoder handles low-level conversion of Krita tile payloads into Unity pixel data. The class is internal and is used by KraParser.

internal static byte[] DecodeKritaTileV2(byte[] tilePayload, int pixelSize, int tileWidth, int tileHeight)

Decodes one Krita tile payload. The first byte is used as a data flag. RAW data is copied directly, while compressed data is decompressed through LZF and then delinearized.

Supported flags:

Flag Meaning
0 Raw tile data
1 LZF-compressed tile data

internal static byte[] DelinearizeColors(byte[] linearized, int pixelSize)

Converts Krita channel-linearized color data into pixel-interleaved data. This changes data from channel blocks into per-pixel layout. 

// Conceptual conversion:
RRRR GGGG BBBB AAAA
// into:
RGBA RGBA RGBA RGBA

internal static Color32[] RawRgbaToPixels(byte[] rawTileData, int tileWidth, int tileHeight, byte opacity)

Converts decoded raw tile bytes into Unity Color32[]. It also converts BGRA channel order to RGBA and applies Krita layer opacity to pixel alpha. 

finalAlpha = pixelAlpha * layerOpacity / 255

KraTextureUtils

KraTextureUtils contains the most important public helper methods for pixel placement, layer merging, texture creation, alpha blending and editor-side PNG/sprite export.

public static void PasteTilePixelsIntoLayerPixels(...)

Pastes a tile pixel buffer into a full image-sized layer pixel buffer. It also converts Krita Y coordinates into Unity texture coordinates. 

KraTextureUtils.PasteTilePixelsIntoLayerPixels(
    layerPixels,
    imageWidth,
    imageHeight,
    tilePixels,
    tileWidth,
    tileHeight,
    tileX,
    tileY
);

public static Color32[] MergeLayerPixels(int width, int height, IReadOnlyList<Color32[]> layersPixels)

Merges multiple layer pixel arrays into one final pixel array. This method is more efficient than repeatedly blending through Texture2D.GetPixels32 and Texture2D.Apply. 

Color32[] mergedPixels = KraTextureUtils.MergeLayerPixels(width, height, layersPixels);

public static void BlendLayerIntoPixels(Color32[] dstPixels, Color32[] srcPixels)

Blends one source layer into a destination pixel buffer. Fully transparent pixels are skipped. Fully opaque pixels replace the destination directly.

public static Color32 AlphaBlend(Color32 src, Color32 dst)

Standard source-over alpha blending between two Color32 values. 

Color32 blended = KraTextureUtils.AlphaBlend(src, dst);

public static Texture2D CreateTextureFromLayerPixels(KraImageData imageData, int layerIndex)

Creates a Unity Texture2D from a selected layer inside KraImageData. 

Texture2D texture = KraTextureUtils.CreateTextureFromLayerPixels(imageData, layerIndex);

public static Texture2D CreateTextureFromLayerPixels(int width, int height, Color32[] layerPixels)

Creates a Unity Texture2D from a raw Color32[] pixel buffer. 

Texture2D texture = KraTextureUtils.CreateTextureFromLayerPixels(width, height, layerPixels);

public static void AddLayerPixelsToTexture(Texture2D targetTexture, Color32[] layerPixels, int imageWidth, int imageHeight)

Adds a layer pixel array into an existing texture by reading the texture pixels, blending the layer, then applying the result back to the texture.

This method is useful for debugging or simple workflows, but for performance-sensitive merging prefer MergeLayerPixels and create the texture only once at the end.

public static void AddLayerTextureToTexture(Texture2D targetTexture, Texture2D layerTexture, int imageWidth, int imageHeight)

Similar to AddLayerPixelsToTexture, but uses another Texture2D as the source layer.

public static void SaveTextureAsAsset(Texture2D tex, string path, ...)

Editor-only method. Saves a texture as a PNG file and optionally refreshes the Asset Database and applies texture importer settings. 

KraTextureUtils.SaveTextureAsAsset(
                        texture,
                        pngFilePath,
                        refreshAssetDatabaseInstant: false,
                        refreshAssetDatabaseWithDelay: true,
                        setImporterSettings: true
                    );

public static void SaveTextureAsSprite(Texture2D texture, string fullPath, float pixelsPerUnit = 100f, ...)

Editor-only method. Saves a texture as a PNG file and configures the imported PNG as a Unity sprite. 

KraTextureUtils.SaveTextureAsSprite(
    texture,
    pngFilePath,
    pixelsPerUnit: 100f,
    refreshAssetDatabaseInstant: false,
    refreshAssetDatabaseWithDelay: true
);

public static Color32[] ApplyMaskToPixels(Color32[] layerPixels, Color32[] maskPixels)

Applies a mask to a set of pixels, resulting in a new array of pixels where the mask determines transparency.

public static Color32[] CombineMasksPixels(int width, int height, List masksPixels)

Combines multiple mask pixel arrays into one final mask pixel array. The result is a single mask where any non-transparent pixel from any input mask will be opaque in the output.

public static string FullPathToAssetPath(string fullPath)

Converts a full system path inside the Unity project into an asset path beginning with Assets/. 

string assetPath = KraTextureUtils.FullPathToAssetPath("C:\Unity\MyProject\Assets\Enemy.kra");
// assetPath will be "Assets/Enemy.kra";

Data classes

KraImageData

Stores image-level data: width, height, name, background color, layer array and merged image texture.

  • Width
  • Height
  • Name
  • BackgroundSimpleColor
  • Layers
  • MergedImage

KraLayerData

Stores metadata and pixel data for one Krita layer or multiple layersIds if NodeType == grouplayer

  • Opacity
  • FileName
  • LayerName
  • NodeType
  • Uuid
  • TileWidth, TileHeight
  • PixelSize
  • TileCount
  • LayerPixels
  • LayersIdsInGroup

KraTileData

Simple tile data container. Currently useful as a structure for possible future tile-level storage or debugging.

  • TileIndex
  • X, Y
  • Type
  • Size
  • TilePixels
  • Flag

KraImportedAsset

Empty ScriptableObject used as the main imported object for .kra assets. This prevents the first generated texture from becoming the main asset.

KraScriptedImporter

KraScriptedImporter is the Unity ScriptedImporter for .kra files. It stores user settings, runs parsing, creates merged outputs and adds subassets to Unity.

Serialized and non-serialized data

Field Purpose Serialized?
LayersDatabase Heavy runtime cache with layer pixels. No
LayersInfo Light layer IDs for UI and saved state. Yes
LayersSave User-defined merged layer settings. Yes

Editor UI

The custom inspector is built with UI Toolkit. It allows the user to create merged layer outputs, select sublayers, reorder sublayers, remove entries and configure export settings.

Editor extension methods

KraImporterEditorExtensions provides simple fluent helpers for UI Toolkit elements.

WithClass

element.WithClass("my-class");

Adds a USS class and returns the element.

WithTextFoldout

new Foldout().WithTextFoldout("Export settings");

Sets foldout text and returns the foldout.

WithTextButton

new Button().WithTextButton("+");

Sets button text and returns the button.

Notes and limitations

  • The importer currently focuses on RGBA-like layer data.
  • Complex Krita blending modes and filters are not represented.
  • Large images can be expensive to decode and merge.
  • Only mask that is supported is transparent mask.

Roadmap

  • Masks: filter, selection
  • Complex Krita blending modes
  • Import and manipulate animations in importer and export to Animator animation
