# Room

## 1. Назначение

Комната является основным игровым пространством `Still Awake?`.

Большая часть игрового процесса происходит внутри одной комнаты. Игрок изучает помещение, взаимодействует с объектами, ищет полезные предметы, наблюдает за происходящим и использует различные укрытия.

---

# 2. Общая планировка

Комната имеет прямоугольную форму.

Основные элементы расположены следующим образом:

* верхняя стена — большое окно;
* перед окном — небольшой стол и стул;
* левая стена — дверь, выключатель, вешалка и компьютерный стол;
* правая стена — шкаф, тумбы/полки с зеркалом и холодильник;
* задняя часть комнаты — кровать.

Камера игрового процесса располагается относительно кровати таким образом, чтобы основная часть комнаты была видна перед игроком.

Условная схема:

```text
┌─────────────────────────────────────────────────────────────┐
│                         ОКНО                    ХОЛОДИЛЬНИК |
│                  ┌───────────────┐                ┌─────┐   │
│                  │  СТОЛ + СТУЛ  │                │     │   │
│                  │    movable    │                │     │   │
│                  └───────────────┘                └─────┘   │
│                                                    ТУМБЫ    │
│                                                  + ЗЕРКАЛО  │
│                                                  ┌────────┐ │
│ ВЕШАЛКА                                          │        │ │
│ ДВЕРЬ                                            │        │ │
│ ┌────┐                                           │        │ │
│ │    │                                           │        │ │
│ └────┘                                           │        | │
│ ВЫКЛ.                                            |        | │
│ СТОЛ + НОУТБУК                                   └────────┘ │
│ ┌───────────┐                                    ┌────────┐ │
│ │   LAPTOP  │                                    │  Ш     │ │
│ └───────────┘                                    │  К     │ │
│                                                  │  А     │ │
│                 ┌───────────────────────┐        │  Ф     │ │
│                 │        КРОВАТЬ        │        └────────┘ │
│                 │                       │                   │
│                 └───────────────────────┘                   │
└─────────────────────────────────────────────────────────────┘
```

Схема является концептуальной и может изменяться после создания первого визуального прототипа комнаты.

# 3. Основные зоны

Комната условно разделяется на несколько игровых зон:

1. Зона окна.
2. Компьютерная зона.
3. Входная зона.
4. Зона шкафа.
5. Зона зеркала и тумб.
6. Зона холодильника.
7. Зона кровати.

Каждая зона должна иметь собственные интерактивные элементы и потенциальные игровые ситуации.

---

# 4. Окно

Окно расположено по центру верхней стены комнаты.

Оно является одним из основных визуальных ориентиров помещения.

Перед окном находятся:

* небольшой стол;
* стул.

На окне находятся шторы.

## Взаимодействия

Игрок может:

* посмотреть в окно;
* взаимодействовать с занавесками;
* открыть/закрыть окно;
* наблюдать за происходящим снаружи.

Точный набор действий — `TBD`.

## Игровая функция

Окно используется для:

* наблюдения за улицей;
* создания атмосферы;
* сюжетных событий;
* появления подозрительных объектов или человека.

Появление сталкера в окне не должно происходить слишком часто.

---

# 5. Стол перед окном

Перед окном расположен небольшой стол со стулом.

Стол должен быть достаточно лёгким, чтобы его можно было передвинуть.

## Взаимодействия

Игрок может:

* осмотреть стол;
* передвинуть стол;
* исследовать предметы на столе;
* взять некоторые предметы.

## Игровая функция

Перемещение стола создаёт шум.

Это может привести к привлечению внимания сталкера.

На столе также могут находиться полезные предметы.

---

# 6. Левая часть комнаты

Левая часть комнаты содержит основную рабочую и входную зоны.

Здесь находятся:

* входная дверь;
* выключатель;
* вешалка;
* компьютерный стол;
* ноутбук.

---

# 7. Входная дверь

Дверь расположена на левой стене ближе к верхней части комнаты.

Дверь является одним из основных источников напряжения.

## Взаимодействия

Игрок может:

* проверить дверь;
* открыть дверь;
* закрыть дверь;
* запереть дверь;
* прислушаться;
* посмотреть через глазок.

## Возможные события

Возле двери могут происходить:

* стук;
* шаги;
* попытка открыть дверь;
* голос;
* другие звуки.

Дверь может использоваться в сюжетных событиях и проверках безопасности.

---

# 8. Выключатель

Выключатель расположен рядом с входной дверью.

Он управляет основным освещением комнаты.

## Взаимодействия

* включить свет;
* выключить свет.

## Игровая функция

Состояние света влияет на:

* видимость;
* поиск предметов;
* потенциальную заметность игрока.

Подробные правила описаны в `gameplay.md`.

---

# 9. Вешалка

Вешалка расположена рядом с входной дверью.

На ней могут находиться:

* одежда;
* верхняя одежда;
* сумка;
* другие личные вещи.

## Взаимодействия

Игрок может осматривать карманы некоторых вещей.

Внутри могут находиться:

* ключи;
* деньги;
* записки;
* мелкие предметы.

Содержимое карманов может зависеть от текущего состояния игры.

---

# 10. Компьютерный стол

Компьютерный стол расположен в левой части комнаты.

На нём находится ноутбук и различные личные предметы.

Вокруг могут находиться:

* зарядные устройства;
* кружка;
* книги;
* кабели;
* канцелярские принадлежности;
* другие бытовые предметы.

## Игровая функция

Компьютер используется преимущественно для получения информации.

Подробная механика описывается в `gameplay.md`.

# 11. Ноутбук

Ноутбук расположен на компьютерном столе.

Возможные функции:

# 12. Правая часть комнаты

Правая часть комнаты содержит:

* большой шкаф;
* тумбы/полки;
* зеркало;
* холодильник.

Эта сторона комнаты содержит несколько важных интерактивных объектов.

---

# 13. Шкаф

Большой шкаф расположен на правой стене ближе к игроку.

Шкаф должен быть достаточно большим для того, чтобы персонаж мог спрятаться внутри.

## Взаимодействия

Игрок может:

* открыть шкаф;
* осмотреть содержимое;
* искать предметы;
* спрятаться внутри;
* наблюдать за комнатой через небольшую щель.

## Поиск предметов

Некоторые полезные предметы могут находиться внутри шкафа.

При поиске может потребоваться дополнительное освещение.

Использование фонарика потенциально увеличивает риск обнаружения.

## Укрытие

Шкаф является одним из основных укрытий.

Преимущества:

* хорошая скрытность;
* возможность наблюдать за комнатой;
* возможность переждать опасность.

Недостатки:

* ограниченное пространство;
* сталкер может открыть шкаф;
* использование света может привлечь внимание.

---

# 14. Тумбы и полки

Далее по правой стене расположены небольшие тумбы или полки.

Они используются для хранения личных вещей.

На них могут находиться:

* косметика;
* книги;
* предметы ухода;
* фотографии;
* мелкие личные вещи;
* потенциально полезные предметы.

## Игровая функция

Тумбы могут использоваться для:

* поиска предметов;
* получения информации;
* создания атмосферы;
* небольших сюжетных событий.

Не каждый предмет на тумбах должен быть интерактивным.

---

# 15. Зеркало

Над тумбами расположено большое настенное зеркало.

Зеркало должно быть хорошо заметно из основной игровой позиции.

Оно является важным интерактивным объектом.

## Взаимодействия

Игрок может:

* посмотреть в зеркало;
* наблюдать отражение комнаты;
* взаимодействовать с зеркалом;
* разбить зеркало.

## Атмосферная функция

Зеркало может использоваться для создания психологического напряжения.

Например:

* игрок замечает что-то в отражении;
* отражение позволяет увидеть часть комнаты под другим углом;
* в определённых ситуациях отражение отличается от ожидаемого.

Такие события должны использоваться умеренно.

## Разбитие зеркала

Зеркало можно разбить.

Разбитие создаёт громкий шум.

Это может привлечь внимание сталкера.

После разбивания могут появиться осколки.

Осколок потенциально может использоваться как предмет.

# 17. Кровать

Кровать расположена в задней части комнаты.

Она является основной точкой, относительно которой располагается игровая камера.

Кровать частично находится под камерой, поэтому в основной композиции видна только её ближайшая часть.

## Взаимодействия

Игрок может:

* сесть/лечь на кровать;
* спрятаться под кроватью;
* использовать телефон;
* пережидать некоторые события.

## Укрытие под кроватью

Под кроватью можно спрятаться.

Преимущества:

* быстрое укрытие;
* возможность использовать телефон;
* возможность переждать опасность.

Недостатки:

* ограниченный обзор;
* сталкер может проверить пространство под кроватью.

Телефон является важным игровым объектом.

Он может находиться рядом с кроватью или переноситься игроком.

Через телефон доступны:

* сообщения;
* звонки;
* контакты;
* история переписки;
* настройки;
* управление звуком уведомлений.

Телефон является основным каналом общения со сталкером.

Подробная механика описывается в `messaging.md`.

# 19. Предметы в комнате

Комната не должна выглядеть пустой или стерильно организованной.

Предметы должны создавать ощущение реального жилого помещения.

Примеры:

* книги;
* одежда;
* косметика;
* кружки;
* зарядные устройства;
* кабели;
* фотографии;
* канцелярия;
* личные мелочи;
* телефон;
* бытовые предметы.

Предметы делятся на:

### Интерактивные

Имеют игровую функцию.

### Атмосферные

Создают ощущение жизни и характера комнаты.

### Сюжетные

Используются для получения информации или запуска событий.

Необходимо избегать ситуации, когда каждый предмет является интерактивным.

# 20. Освещение

Основное освещение комнаты — слабый тёплый потолочный свет.

Дополнительный источник света — холодный синий лунный свет из окна.

Комбинация освещения должна создавать контраст между:

* безопасным тёплым помещением;
* холодным и неизвестным внешним пространством.

Освещение может изменяться в зависимости от игровых событий.

Возможные события:

* выключение света;
* отключение электричества;
* мерцание лампы;
* изменение внешнего освещения.

Конкретная система освещения — `TBD`.

# 21. Навигация и пространство

В комнате должно оставаться достаточно свободного пространства для:

* осмотра помещения;
* взаимодействия с объектами;
* перемещения;
* быстрого перехода к укрытиям.

Основные игровые объекты не должны полностью перекрывать друг друга.

Особое внимание необходимо уделить:

* доступу к двери;
* доступу к окну;
* доступу к шкафу;
* доступу к кровати;
* доступу к компьютеру;
* видимости зеркала.

---

# 22. Требования к визуальному оформлению

Комната должна выглядеть:

* уютной;
* немного неопрятной;
* жилой;
* правдоподобной;
* визуально понятной.

Необходимо избегать чрезмерно пустого пространства и одновременно не перегружать сцену большим количеством декоративных объектов.

Основной визуальный акцент:

1. окно;
2. стол перед окном;
3. пространство комнаты;
4. правая зона со шкафом и зеркалом;
5. левая зона с компьютером и дверью.

Состояние комнаты должно позволять игроку быстро понимать расположение основных объектов.
